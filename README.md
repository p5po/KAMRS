# KAM Real Estate (شركة كام العقارية) - Web Portal

البوابة الرقمية الرسمية والواجهة المعمارية التنفيذية لشركة كام العقارية (KAM Real Estate) في مدينة الرياض، المملكة العربية السعودية.

---

## 🏛️ نظرة عامة على المشروع (Project Overview)

تم بناء البوابة الإلكترونية لتعكس الهوية المعمارية الراقية للشركة، معتمدةً على:
- **التصميم المعماري الفاخر:** لوحة ألوان رسمية مخصصة (Dark Slate `#16191E`, Deep Slate `#1F242D`, Muted Stone `#847668`, Pure White `#FFFFFF`).
- **اللغة والاتجاه:** لغة عربية متكاملة (`dir="rtl" lang="ar"`) بخط Google Font `Tajawal`.
- **تجربة تفاعلية متجاوبة:** متوافقة 100% مع كافة الشاشات (الهواتف الذكية، الأجهزة اللوحية iPad، والشاشات المكتبية العريضة).
- **التوافق القانوني:** متوافق مع نظام حماية البيانات الشخصية السعودي (PDPL).

## 🌟 المشاريع الأربعة الرئيسية (Flagship Projects)

1. **[كام البرج (KAM Tower)](kam-tower.html):**
   - **الموقع:** حي القيروان، الرياض.
   - **النوع:** برج تجاري وإداري فاخر (13+G دوراً و4 مستويات قبو).
   - **المساحة التأجيرية:** 3,355 م².

2. **[كام المكاتب الخاصة (KAM Private Offices)](kam-private-offices.html):**
   - **الموقع:** حي الملقا، الرياض (تقاطع طريق أنس بن مالك وطريق الملك فهد).
   - **النوع:** مجمع تجاري ومكتبي خاص.
   - **المساحة التأجيرية:** 5,595 م² مساحات مكتبية و1,664 م² معارض.

3. **[كام المكاتب العصرية (KAM Modern Offices)](kam-modern-offices.html):**
   - **الموقع:** حي الملقا، الرياض.
   - **النوع:** مكاتب ومعارض تجارية عصرية.
   - **المساحة الإجمالية:** 5,835 م².

4. **[كام الفلل العائلية (KAM Family Villas)](kam-family-villas.html):**
   - **الموقع:** حي القيروان، الرياض.
   - **النوع:** مجمع سكني عائلي فاخر (24 فيلا مستقلة).
   - **المساحة الإجمالية:** 7,200 م².

## 🚀 التشغيل والمعاينة المحلية (Local Preview & Deployment)

المشروع عبارة عن موقع ويب ثابت (Static Web Application) مبني باستخدام HTML5 و Tailwind CSS و JavaScript ولا يتطلب أدوات بناء معقدة.

### الخيار 1: الفتح المباشر
يمكن فتح أي صفحة مباشرة بالنقر المزدوج على `index.html` في أي متصفح حديث (Chrome, Edge, Safari, Firefox).

### الخيار 2: عبر خادم محلي خفيف (Recommended)

#### باستخدام Python:
```bash
# Python 3
python -m http.server 8000
```
ثم التوجه إلى: `http://localhost:8000`

#### باستخدام Node.js (`serve` أو `live-server`):
```bash
npx serve .
```

#### باستخدام VS Code Live Server:
انقر بيمين الفأرة على `index.html` واختر **"Open with Live Server"**.
